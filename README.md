# AI Agents

Каждый агент — отдельная папка в `agents/` и отдельный проект в bb (раздел в сайдбаре).

## Структура агента

| Путь | Что это |
|---|---|
| `AGENTS.md` | Личность, роль, правила работы. Главный файл. |
| `CLAUDE.md` | Подключает `AGENTS.md` для Claude Code. |
| `.bb/skills/` | Навыки агента — доступны как slash-команды. |
| `.claude/agents/` | Субагенты, которых агент вызывает сам. |
| `.claude/settings.json` | Разрешения и hooks. |
| `.mcp.json` | Внешние инструменты (MCP-серверы). |
| `knowledge/` | База знаний: документы, справочники, примеры. |
| `memory/` | Долговременная память, агент пополняет её сам. |
| `scripts/` | Утилиты агента. |

## Новый агент

```sh
./new-agent.sh <slug> "<Имя>" "<Роль одной фразой>"
# пример:
./new-agent.sh coder "Coder" "Senior-разработчик: пишет и ревьюит код"
```

Скрипт копирует `_template/`, подставляет имя и роль, регистрирует проект в bb.
Дальше допишите `agents/<slug>/AGENTS.md` под задачу.
