---
name: design-metrics
description: Разработать набор метрик и OEC для продукта или эксперимента по главам 6–7 — goal, driver, guardrail, debug; проверить на чувствительность и манипулируемость; предложить веса OEC.
---

1. Выясни продукт, миссию, бизнес-модель, что уже меряют, OKR.
2. Вызови субагента `metrics-architect` с этим контекстом.
3. Для ключевых метрик проверь чувствительность: есть данные — `abdata.py aa` (дисперсия, выбросы); нет — `abstat.py power` по оценке sd.
4. Предложи, как **валидировать** driver → goal: эксперимент для проверки метрики, корпус исторических экспериментов, опросы, UER.
5. Итог:
   - таблица (метрика · роль · формула · единица · направление · α-уровень);
   - OEC (веса или правила решения по 4 сценариям);
   - список guardrails;
   - риски манипуляции;
   - план эволюции метрик.
