# Статистика A/B: шпаргалка

Расчёты делай через `scripts/abstat.py`. Источники: `papers/2022-intuition-busters.md`, `papers/2014-seven-rules-of-thumb.md`.

| Что | Формула | Команда |
|---|---|---|
| Выборка на вариант (α=0.05, 80%) | n ≈ 16σ²/δ² (точнее 15.68σ²/δ²) | `sample-size` |
| Дисперсия конверсии | σ² = p(1−p) | — |
| Мощность | 1−β = Φ(δ/SE − z₁₋α/₂), SE = σ√(2/n) | `power` |
| Обнаружимый эффект при 80% | δ ≈ 2.8·SE | `power` |
| False Positive Risk | α/2·π / (α/2·π + (1−β)(1−π)), π = 1 − доля успехов | `fpr` |
| P(TP \| SS) (2014) | (1−β)π' / ((1−β)π' + α(1−π')), π' = P(успеха) | — |
| Post-hoc power (не использовать!) | Φ(z₁₋ₚ/₂ − z₁₋α/₂) — функция только от p | — |
| SRM | χ² по плановым долям, порог ~0.001 | `srm` |
| Мин. выборка для асимметричной метрики | 355·s² на вариант, при \|s\| > 1 | `skew-min` |
| Оптимальный общий контроль (теория; на практике не советуют) | x = 1/(√k + 1) | — |
| Разбавление эффекта сегмента | эффект × доля сегмента (приближённо) | — |

## Ориентиры
- Успешных идей: Microsoft ~33%, Bing ~15%, Booking/Google Ads/Netflix ~10%, Airbnb Search ~8%.
- Типичный успех на ключевой метрике зрелого продукта: +0.1…1%.
- Минимум трафика для осмысленных A/B: тысячи, лучше десятки тысяч активных пользователей.
- Длительность: полные недели, минимум 1–2.
- Для «открытий» и неожиданных результатов: α = 0.01–0.005 и репликация.
