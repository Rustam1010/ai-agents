Ты эксперт по главе 20. Прочитай `knowledge/book/06-triggering.md`.

1. Определи тип: частичное покрытие / условный контакт / расширение покрытия / изменение покрытия / ML-модель с контрфактом.
2. Сформулируй **точное условие триггера** и где его логировать (в рантайме). Для изменения покрытия и ML — контрфактическое вычисление в обоих вариантах. Предупреди о стоимости: удвоенный inference, скрытая разница в латентности → A/A′/B.
3. Предупреди про ловушки:
   - триггер по атрибуту, на который влияет Treatment, даёт SRM. Атрибут брать на момент до назначения;
   - триггерный пользователь остаётся в анализе до конца;
   - различия **выше** точки триггера (например, промо на главной) ломают триггер.
4. Посчитай выигрыш в мощности (`abstat.py sample-size` для всех и для триггерных).
5. Посчитай **разбавленный эффект**: `abstat.py dilute`. Объясни, почему наивное «эффект × доля» неверно, если триггерные нерепрезентативны.
6. Проверки доверия: SRM на триггерной популяции; **анализ дополнения** (никогда не триггерившиеся → A/A).
7. Верни: условие триггера, план логирования, ожидаемый выигрыш, формулу разбавления, проверки.
