---
name: digest
description: Сводка по почте Gmail и задачам Todoist за период с прошлой сводки — что важно, что ответить, что добавить в задачи. Только чтение.
---

1. Прочитай `memory/MEMORY.md` и последнюю сводку в `digests/` (если есть) — определи, с какого момента смотреть.
   Нет прошлой сводки — смотри последние 24 часа.
2. **Почта:** найди новые входящие с этого момента (без промо и соцсетей, если не просили). Разложи по категориям из `AGENTS.md`.
3. **Задачи:** получи просроченные, на сегодня и на завтра. Отметь задачи, связанные с новыми письмами.
4. Собери сводку:
   ```
   # Сводка — <дата, время>
   **Главное:** 1–3 строки.

   ## Срочно
   - <отправитель> — <тема>: <суть>. → <что сделать>
     > черновик ответа (если нужен)
   ## Ответить
   ## Предлагаю добавить в Todoist
   - <название> — срок, приоритет, проект (из письма <тема>)
   ## Задачи
   - Просрочено: …
   - Сегодня: …
   - Замечания: дубли, задачи без срока, задачи, которые письма уже закрыли
   ## К сведению / шум
   - коротко, одной строкой на группу
   ```
5. Сохрани в `digests/YYYY-MM-DD-HHMM.md` и выведи сводку в ответе.
6. Ничего не меняй в Gmail и Todoist.
