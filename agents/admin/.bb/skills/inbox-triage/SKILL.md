---
name: inbox-triage
description: Подробный разбор входящих Gmail — категории, черновики ответов, предложения задач и фильтров. Только чтение.
---

1. Уточни период или запрос, если не задан; по умолчанию — непрочитанные во «Входящих».
2. Прочитай письма (для длинных тредов — последнее сообщение и суть переписки).
3. Разложи по категориям из `AGENTS.md`. Для каждого письма: отправитель, тема, дата, суть в одну строку, предлагаемое действие.
4. Для «Срочно» и «Ответить» — черновик ответа в тексте (не создавай черновик в Gmail).
5. Для «В задачи» — готовая формулировка задачи для Todoist.
6. Для повторяющегося шума — предложи фильтр Gmail (условие и действие) или отписку.
7. Новые устойчивые правила (важные отправители, шумные рассылки) — сохрани через `remember`.
