1. `python3 scripts/nhl.py sync --boxscores 0`.
2. Для матчей из `data/bets.csv` без результата — найти счёт (`team TEAM --last 3`) и заполнить result и profit.
3. Для дня целиком: `slate --date <вчера>` показывает модель и фактический счёт рядом.
4. Разбор ошибок: вратарь, пустые ворота, овертайм (особенно для ≤4), большинство. Систематика → запись в `memory/` через `/remember`.
5. Раз в месяц — `backtest` на текущем сезоне, чтобы видеть, не деградировала ли модель.
