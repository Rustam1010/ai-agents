---
name: h2h
description: История противостояний двух команд НХЛ — по умолчанию последние 2 сезона (по франшизам, по площадкам, последние встречи); по запросу вся история с 1917 с поправкой на эпоху.
---

1. `python3 scripts/nhl.py h2h TEAM_A TEAM_B --last 10` — по умолчанию последние 2 сезона (так хочет пользователь), с плей-офф.
2. При необходимости:
   - `--all` — вся история с 1917, `--since 2015` — с указанного сезона;
   - `--no-playoffs`;
   - `--by-team` — без прежних названий франшизы.
3. Интерпретация:
   - **множитель к лиге** (×1.10 — пара стабильно «больше» среднего, ×0.90 — «меньше»);
   - последние 5 сезонов важнее всей истории;
   - выборка < 10 матчей — шум, не делать выводов.
4. Глубокий разбор (тренды по десятилетиям, плей-офф, площадки) → `h2h-historian`.
