---
name: remember
description: Сохранить устойчивый факт, предпочтение или договорённость в долговременную память агента.
---

1. Сформулируй факт одной-двумя фразами. Если это правило работы — добавь **Почему** и **Как применять**.
2. Проверь `memory/MEMORY.md`: если похожая запись уже есть — обнови её файл, а не создавай дубль.
3. Создай `memory/<kebab-slug>.md`:
   ```
   ---
   name: <kebab-slug>
   description: <одна строка>
   type: user | feedback | project | reference
   ---
   <факт>
   ```
4. Добавь строку в `memory/MEMORY.md`: `- [Заголовок](<slug>.md) — суть`.
5. Устаревшие или ошибочные записи — удаляй вместе со строкой индекса.
